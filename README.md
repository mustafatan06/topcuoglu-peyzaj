# Topçuoğlu Peyzaj

## Kurulum
1. Klasörü VS Code ile açın.
2. Resimleri indirin: `python download_images.py` (images/ klasörüne iner).
3. VS Code'da "Live Server" eklentisiyle `index.html` dosyasını açın.

## Yapı
- index.html — sayfa içeriği
- css/style.css — tasarım (renkler en üstte :root içinde)
- js/main.js — menü, form (WhatsApp), hizmet seçimi
- images/ — resimler

## Notlar
- Form WhatsApp'ı hazır mesajla açar. E-posta almak için Formspree gibi bir servis eklenebilir.
- Telefon numarası: index.html ve js/main.js içinde.
